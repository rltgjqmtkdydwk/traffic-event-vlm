## 5. GT 파일 형식

`data/gt/gt.csv` (원본 영상과 함께 레포에 올리지 않음)

| 열         | 설명                                                                     | 예시                    |
| ---------- | ------------------------------------------------------------------------ | ----------------------- |
| video_id   | 클립 파일 이름 (확장자 제외)                                             | `loc1_20261108_1530_03` |
| event_type | `jaywalk` / `pm_violation` / `right_turn_no_stop` / `none` / `uncertain` | `pm_violation`          |
| subtype    | pm_violation일 때만                                                      | `no_helmet`             |
| start_sec  | 클립 기준 시작 초                                                        | `4.5`                   |
| end_sec    | 클립 기준 끝 초                                                          | `9.0`                   |
| difficulty | `easy` / `hard`                                                          | `hard`                  |
| note       | 자유 기록                                                                | `버스에 일부 가려짐`    |

클립 파일 이름 규칙: `장소코드_날짜_시작시각_번호`
